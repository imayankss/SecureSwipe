03   Architecture 1:06 – 1:48

Six stages. Each one carries a guarantee, not a hope.

score → rank under capacity → route → explain → audit → replay / fail closed

01 — SCORE

Checksum-verified bundle

A local bundle normalizes fields into its own recorded order and runs the estimator.

Deterministic · zero LLM tokens
02 — RANK

Top-B under a fixed budget

Transactions are ordered by score; the top B are selected for the day.

Workload is chosen, not discovered
03 — ROUTE

Two outcomes only

Each case becomes human_review or below_review_threshold.

Never an approve, block, or decline
04 — EXPLAIN

Provenance, not vibes

Score meaning, calibration status and threshold all come from bundle provenance.

No browser-side assumptions
05 — AUDIT

Hash-chained receipt

A successful decision gets a chained, allowlisted, tamper-evident record.

No raw body, PAN, CVV or credentials
06 — REPLAY

Idempotent, or nothing

An identical request replays the original response without re-scoring; an invalid path returns no decision.

Idempotent · fails closed
