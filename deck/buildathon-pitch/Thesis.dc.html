02   The decision 0:48 – 1:06

It ranks. It never blocks.

Every SecureSwipe outcome is one of exactly two signals to a human queue. There is no autonomous payment action anywhere in the system, and the tests enforce that rather than the README claiming it.

human_review below_review_threshold

Workload is chosen, not discovered

You set a daily review budget B. The system ranks by score and takes the top B. A threshold is an output of that budget, never an input.

The cost of recall is on the same slide

Every operating point is published with the legitimate-customer workload it creates. No tier is marked optimal, because optimality depends on costs this evaluation does not contain.

Refusal is a first-class result

A missing, corrupt or unverifiable model bundle returns no decision at all. The system fails closed and says so, instead of silently selecting a fallback.

It does not authorize · approve · capture · block · decline  —  a payment. Ever.
